# DSC8307 — Assignment 1 (Advent 2026)

Two reproducible Jupyter notebook projects for Data Mining, Modeling and Analytics.

## Contents
- `01_Bank_Marketing.ipynb`: EDA, leakage-safe pre-call features, majority baseline, three classification models, validation model ranking, operational threshold sensitivity, and test evaluation.
- `02_Concrete_Strength.ipynb`: EDA, mean baseline, linear/nonlinear comparison, five-fold cross-validation, test residual diagnostics, and causality discussion.
- Original supplied CSV datasets and their README files.
- `requirements.txt`: Python dependencies.

## Run
Python 3.10+ recommended. In a terminal:

```bash
python -m venv .venv
# macOS/Linux: source .venv/bin/activate
# Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
jupyter notebook
```

Open each notebook and select **Kernel → Restart & Run All**. Run from the repository root. Outputs are computed from the original datasets; model rankings and recommendations are generated by code, not assumed in advance.

## Methodological caveats
Random holdouts do not establish future campaign performance or new-mix generalization. The bank threshold uses an illustrative value model, not measured uplift. Concrete feature importance is not causal evidence.
